1. 概要

タイトル（仮）: Web Shooting

技術: HTML5 Canvas + JS / LAMP（PHP+MySQL） / Docker

表示: 800×600（pixelated / imageSmoothing off）

保存: プレイヤー名＋パスワード（サーバ保存）、セッションCookie

2. 操作

移動: WASD

照準: マウス位置（角度θ）

射撃: Space / 左クリック（連射）

ダッシュ: Shift（0.2–0.3s無敵、CD有）

ポーズ: P
※ 将来: ゲームパッド（LS移動/RS照準/RT射撃/LBダッシュ）

3. ゲームモード

Story: 雑魚Wave→ボス／★評価（ノーミス・タイム・コンボ）

Survival: 無限ウェーブ／最長生存でランキング（降順）

BossRush: ボス連戦／最短クリアでランキング（昇順）

Daily: 日替わりseed＋固定ミューテーター（専用ランキング）

4. コアループ

Login → Main Menu（Play/Upgrades/Workshop/Ranking/Stats/Options）→
Stage Select（難易度）→ Play（イベント波/鍵宝箱あり）→ Result（スコア・素材）→ 強化/クラフト

5. 敵・弾・挙動

雑魚: 直進 / 蛇行 / 停止→突進 / 瞬間移動 / 分裂

エリート: 体力↑・ドロップ豪華、鍵持ちが稀に出現

弾幕: n-Way / 放射 / 収束→拡散 / レーザー

当たり判定: 自機=円(r≈12), 弾=円(小), レーザー=矩形

6. 難易度トグル

EASY: 弾速×0.9、同時出現-1、敵HP×0.9

NORMAL: 1.0 / ±0 / 1.0

HARD: 弾速×1.15、同時出現+2、敵HP×1.1、エリート出現率↑
※ ランキングは難易度別に分離（将来 scores.meta_json.difficulty 付与）

7. イベント波 & 鍵/宝箱

流星雨: 一定時間、落下物＋弾密度↑／素材ドロップ↑

サプライドローン: 背面回り込み→撃破で素材束

鍵→宝箱: エリート撃破で鍵→終盤宝箱で素材／モジュール断片など

8. 成長・経済

素材: Alloy / Flux / Chip / Core

強化（Lv制）: Attack / Rate / Spread / Speed / Shield / Magnet
コスト例: Alloy = ceil(base * 1.6^(Lv-1))（段階でFlux/Chip/Core追加）

武器: メイン固定＋サブ1枠（Pierce/Charge/Homing）

モジュール（受動3枠）: 弾速+10%、マグネット+20%、ダッシュCD-20% ほか（レア度あり）

武器改造ツリー: Pierce「貫通2＋反射1」/ Charge「最短チャージ-25%」等

Workshop（クラフト）: recipes.json で定義

9. ランキング仕様

種別: Survival（最長）/ BossRush（最速）/ Stage / Daily

タイブレーク: duration_ms → damage_taken → created_at → id

表示: 上位N + around-me（前後±5）、自分を上部ピン留め

GET /api/ranking.php?mode=survival|bossrush

GET /api/daily.php

12. DB（実装済）

players / sessions / progress / inventory / upgrades / weapons / scores / achievements / settings

ビュー: v_survival_best / v_bossrush_best

13. UIフロー

Main → Play（Stage Select + 難易度） / Upgrades / Workshop / Ranking / Stats / Options

Result: スコア・素材・★・ハイライト（自己ベスト更新）

14. 品質・パフォーマンス

弾/エフェクトはオブジェクトプール、空間分割で衝突回数削減、上限管理

1フレーム目安: 16.67ms（60fps）、GCスパイク抑制

視覚: ヒットストップ短／軽い画面揺れ（設定でOFF可）

15. アート/アセット指針

ドット絵: 32×32基準（ボスは96×96）／中心ピボット

360°は16方向スナップ（まずはこれ、後で砲塔分割も可）

弾: 画像なしの図形（円/矩形）で視認性優先

16. アクセシビリティ

色覚パレット切替、被弾アウトライン強調、リデュースドモーション、キーリマップ
